## 📖 About the Project

ArtSpace is an Android application developed using Java and XML. It allows users to explore six famous artworks and learn about their titles, artists, and creation years.

## ✨ Features

- Browse six famous artworks.
- Navigate between artworks using Next and Previous buttons.
- Display artwork titles, artists, and years.
- View detailed information about each artwork.
- Open websites using Implicit Intents.
- Preserve the current artwork when rotating the screen.

## 🛠️ Technologies Used

- Java
- XML
- Android Studio
- View Binding
- Explicit Intents
- Implicit Intents
- Activity Lifecycle
